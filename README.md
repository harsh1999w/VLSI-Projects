# VLSI-Projects - RTL Design using Verilog

This repository contains my VLSI lab projects in Verilog.

### Project 1: Half Adder
- Implemented using Dataflow modeling
- Files: half_adder.v 
- Tool: EDA Playground 

### Project 2: Full Adder
- Implemented using 2 Half Adders logic
- Files: full_adder.v 

### Project 3: 4-bit ALU
- Designed 4-bit ALU with ADD, SUB, AND, OR operations using MUX logic
- Implemented Carry handling and case-based control
- Files: alu_4bit.v 
- Tool: EDA Playground (Icarus Verilog) / EPWave
- Verified with simulation and waveforms

### Project 4: 4:1 Multiplexer
- Implemented 4:1 MUX using behavioral modeling
- Files: mux_4to1.v 
- Tool: EDA Playground (Icarus Verilog) / EPWave
- Verified with simulation and waveforms

### Project 5: 101 Sequence Detector (Overlapping)
- Designed Mealy FSM for 101 overlapping detection
- File: seq_101_detector.v
- Tool: EDA Playground / EPWave
- Verified with simulation
